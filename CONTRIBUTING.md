# Contributing

Thanks for helping improve Greenfield UX.

## Before opening a pull request

1. Keep `skills/greenfield-ux/SKILL.md` as the canonical skill definition.
2. Make rules concrete enough for an agent to implement or verify.
3. Avoid duplicating guidance already covered by an adjacent section.
4. Preserve the skill name, invocation metadata, and installer paths.
5. Run the install and uninstall scripts in a temporary home directory when changing them.

## Pull requests

Explain the product problem, the behavior the new guidance creates, and how you checked the result. Focused changes are easier to review and maintain.
